# 原點 · 當前版本唯讀觀察入口

本包只提供當前原點的觀察入口與公開介面可用性檢查，不提供替代場景、不生成世界，也不啟動模型。它明確指向既有 `5219` renderer 與 `8844` observer，不採其他預設埠或舊世界回退。

**現況為 PARTIAL。自主生活目前為部分完成，正式 Stage2 未完成，居民目前處於安靜觀察狀態。** 這是交接現況；本包沒有以新的 live 投影證明居民狀態，也沒有把介面可讀當成自主生活成功。

## 執行

需要 Node.js 20 或以上，零第三方依賴，不必安裝套件。

```sh
node server.mjs
```

開啟 `http://127.0.0.1:5298/`。點「開啟現版觀察畫面」會打開既有服務：

```text
http://127.0.0.1:5219/?render=construction&view=resident&shared=1&observer=8844
```

本入口不會啟動、重啟或修改該服務。若服務未就緒，畫面本身可能回報中斷；沒有固定 SVG、預錄影片或假場景補上。檢查按鈕只對固定 `8844/api/shared-test/base` 與 `/frame` 發出 GET，沒有自動輪詢。base 本文立即丟棄；frame 有界讀取後丟棄，不保存世界資料，也不下載核心生成規則。

## 當前狀態與限制

依交接，base-18 readiness 的入口檔曾由總管核對存在；這不等於真 MUSE 成功。指定 renderer 曾實際顯示「畫面中斷，請重新載入」，不能據此說 base-18 或居民已可見。這些是交接時的觀察，不是本包自行核實的最新 runtime 終態。

「公開介面可讀」只表示當次 HTTP/格式檢查通過，未驗完整 projection admission、世界身份、已接受事件、持久保存、獨立重播或供應商結果。醒來、認人、記得、建造四個自主動作，在本包均未取得真模型同鏈證據。沒有用四張導覽卡或假供應商補足這些缺件。

真模型成果必須由該次供應商結果、已接受事件、保存與重播共同證明；本包沒有包含那些私人執行資料，所以不能獨立簽收真模型成果。

## 分工與原則

人類只提供可以被忽略的引導，不控制居民。原執行者維持現有 runtime 與真正測試；封裝者只整理受限觀察入口，驗證者核對入口與限制，交件者親自檢查及提交。此包沒有居民指令、模型呼叫、世界寫入、服務管理或發布功能。

## 檢查

```sh
node --test tests/public-reader.test.mjs tests/observer-entry.test.mjs
```

第一個測試保留既有公開讀取器的 bounded-streaming 斷言，其餘只檢查新封裝邊界。測試中的 upstream 是明確的 HTTP test double，不是模型供應商，也不算真 MUSE 呼叫。執行輸出以包外驗證報告為準，不預先宣稱測試通過。

## 刻意排除

未收入白皮書、唯一真相文件、經濟路線、核心生成規則、完整 kernel/generator、完整 renderer 生成依賴鏈、憑證或金鑰載入器、居民私人種子/記憶、即時資料庫、通話目錄、收據、範圍、日誌、錄製、歷史來源膠囊、構建產物或個人資料。
